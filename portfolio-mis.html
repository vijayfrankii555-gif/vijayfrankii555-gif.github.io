4. Reporting Logic

The report is built around clearly defined management calculations rather than manually typed summary figures.

Achievement % = Actual Sales ÷ Target
Variance = Actual Sales − Target
Month-on-Month Growth % = (Current Month − Previous Month) ÷ Previous Month

5. Colour Formatting

  • Green — approved good-performance range.
  • Yellow — watch / management-review range.
  • Red — exception / action range.

6. Power BI Version

Suggested Power BI Management Dashboard

The same reporting model can be used in Power BI with KPI cards, city-wise performance, monthly trend, product analysis and slicers for Month, Region, City and Manager.

Core DAX Measures

Total Sales = SUM(Sales[Revenue])
Total Target = SUM(Sales[Target])
Achievement % = DIVIDE([Total Sales], [Total Target], 0)
Variance = [Total Sales] - [Total Target]

7. Business Value

  • Converts raw sales transactions into management information.
  • Makes target gaps and exceptions visible.
  • Creates a consistent reporting format for monthly review.
  • Provides a foundation for Excel and Power BI dashboards.
